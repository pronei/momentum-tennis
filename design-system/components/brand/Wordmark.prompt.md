The Momentum Tennis wordmark — use for all brand representation; never set the name in another face or draw a different mark.

```jsx
<Wordmark height={52} />                    {/* full lockup */}
<Wordmark variant="word" height={20} />     {/* nav-size, ghosts auto-hide */}
<Wordmark variant="mark" height={40} onField />  {/* avatar / favicon */}
```

Clear space: half the cap height on all sides. Minimum: 16px word height (lockup 24px). The amber ball is non-negotiable — it is "now".
