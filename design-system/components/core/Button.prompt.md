Action pill — every clickable action in the system. Amber primary appears ONCE per view (the booking action); everything else is secondary or ghost.

```jsx
<Button href="#book">Book a free trial class</Button>
<Button variant="secondary" size="sm">View schedule</Button>
<Button variant="ghost" onField>All programs</Button>
```

Labels are short, verb-first, no exclamation points. Never put two primary buttons side by side.
