Select — the dropdown for 4+ options (2–3 short options use SegmentedControl instead). Native select styled square/hairline with the mono ▾ from the nav.

```jsx
<Select label="Court" options={['Court 1','Court 2']} />
<Select label="Player" placeholder="Assign a player" options={[{value:'p1',label:'Maya R.'}]} error="assign this item to a player" />
```
