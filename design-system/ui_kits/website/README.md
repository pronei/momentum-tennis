# Website UI kit — momentum-tennis.com (evolved)

The homepage per the brand brief: strobe hero (slice-treated real photo) → three program cards with the real timetable → camp-day band (dark field, strobe arc + numbered timeline) → proof (coaches, USTA JTT, championship photo) → verbatim founder quote → single CTA band → footer.

- `index.html` — assembled page (React + `_ds_bundle.js`); anchors are live, hover/focus states real.
- `sections.jsx` — Header, Hero, Programs, CampDay, Proof, Quote, CTABand, Footer (exported on `window.MTSections`).

Rules embodied here: one amber CTA action ("Book a free trial class"); photos contained, never full-bleed; numbers only in the camp timeline; all schedule copy verbatim from the live site.
