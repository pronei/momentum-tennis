Camp-day timeline — the second-most memorable element after the hero; use on the camps page and homepage camp section. The ONLY place numbered markers are allowed (the day is genuinely sequential).

```jsx
<CampTimeline />   {/* defaults = real 2026 camp day */}
<CampTimeline items={[{time:'09:00',title:'On-court training',phase:'On court'}]} />
```

Hover/focus a row: that frame turns amber — "now". Don't add icons, don't recolor phases.
