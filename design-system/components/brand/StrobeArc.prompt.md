Stroboscopic bounce-arc — the Momentum signature device; use it wherever motion-over-time needs to be drawn (hero fields, section openers, empty states), never more than once per view.

```jsx
<StrobeArc tone="field" frames={8} annotate height={180} />
```

- `tone="light"` on white/paper; `tone="field"` on court-blue fields.
- `annotate` adds mono `t−7 … t0` frame labels — the Pentagram-style analysis register.
- Rule: the final (amber) ball is "now" — never recolor it, never use two arcs in one view.
